# Branding

Master-Dateien für Energy Joe. Hier ablegen:

- Icon als PNG, quadratisch (1250 × 1250), möglichst mit transparentem Hintergrund
- Grafik für das README
- falls vorhanden: das Logo als SVG – daraus entsteht ein gestochen scharfes Seitenleisten-Icon

Daraus werden erzeugt:

| Ziel | Dateien |
|---|---|
| Home Assistant (Integrationsliste, ab 2026.3) | `custom_components/energy_joe/brand/icon.png` (256 px), `icon@2x.png` (512 px) |
| Panel | `panel/public/` – wird beim Build mit ausgeliefert |
| README | `docs/images/` |
